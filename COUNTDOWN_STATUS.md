# Pilot Window Update

## Current Pilot Window

The current public pilot window is scheduled to remain open until:

**September 30, 2026 — 00:00 UTC**

This date is a planning target.

The public pilot window may close earlier or remain open longer, depending on project priorities, engineering workload, and evaluation capacity.

No additional notice is guaranteed.

## Enterprise Evaluation

Organizations with **10,001+ employees** are encouraged to begin evaluation before the current pilot window ends.

After the pilot window closes, new enterprise pilot intake is expected to be **suspended**.

The suspension may remain in effect for approximately **6–12 months**, while work continues with existing pilot partners.

## During Suspension

- Existing pilot evaluations continue.
- Protocol development continues.
- Public evidence and validation updates continue.
- Protected Core remains private.

## Priority

Engineering time is intentionally focused on:

- Active pilot partners
- Runtime validation
- Protocol evolution
- Production readiness

The objective is to complete existing evaluations before accepting new ones.

## Notice

The pilot window is intentionally flexible.

It may close earlier than September 30, remain open longer, or transition directly into suspension without extending the current intake period.

Organizations interested in evaluating VRP should make contact while the pilot window remains open.
