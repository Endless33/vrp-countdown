THE ENGINEERING DISTINCTION

A network path is not a session.

Transport interruptions can force applications to reconnect, recover state or restart operations. VRP explores an architecture where logical session identity is maintained separately from transport attachment.

Session Independence

Logical session identity is distinct from a single network path.

02 / AUTHORITY

Controlled State

Authority and epoch changes are governed by explicit state rules.

03 / DEFENSE

Replay Containment

Selected stale and replayed operations are subject to rejection.

04 / RECOVERY

Transport Migration

05 / INTEGRITY

Canonical State

Invalid operations should not silently rewrite authoritative state.

Reproducible Validation

Engineering claims should be bounded by test conditions and evidence.
